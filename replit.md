# veachelsell — Telegram-бот магазина

Telegram-бот для ресейл-магазина veachelsell: каталог товаров, поиск, отзывы, избранное, заказы с уведомлением админа, полноценная панель администратора в Telegram.

## Запуск

- Workflow **Telegram Bot**: `cd bots/telegram-bot && python3.11 main.py`
- VPS/локальный запуск: `./run_bot.sh` — при первом запуске создаёт `bots/telegram-bot/.venv`, устанавливает зависимости и запрашивает `BOT_TOKEN` скрытым вводом. Данные магазина сохраняются в `bots/telegram-bot/data/store.json`.
- Логи пишутся в `bots/telegram-bot/bot.log` (можно скачать через `/admin` → «Скачать логи»)

## Секреты и переменные

| Ключ | Где задать | Описание |
|---|---|---|
| `BOT_TOKEN` | Replit Secrets | Токен бота от @BotFather |
| `ADMIN_IDS` | Secrets / config.py | Telegram ID администраторов (через запятую) |
| `SHOP_NAME` | env var / config.py | Название магазина |

### Токены прямо в коде

Открой `bots/telegram-bot/config.py` — там есть раздел с закомментированными переменными:
```python
# BOT_TOKEN_HARDCODED      = "123456:ABC..."
# ADMIN_IDS_HARDCODED      = [123456789]
```
Раскомментируй и заполни — они перекроют env vars.

## Stack

- Python 3.11 + **aiogram 3.x** (FSM, Routers)
- JSON-файл — `bots/telegram-bot/data/store.json`, создаётся автоматически при старте

## Функции бота

**Для покупателей:**
- `/start` — приветствие с фото и главное меню
- 🛍 **Товары** → категории → список → карточка с фото (навигация ◀/▶ по фото)
- 🔍 **Поиск** — по названию и описанию
- ⭐ **Отзывы** — просмотр, добавление с фото и оценкой, ссылка на TG-канал
- 📩 **Контакты** — контактная информация
- ❤️ **Избранное** — сохранить товар, посмотреть список
- ℹ️ **О нас** — описание магазина
- 🛒 **Заказать** — прямо из карточки товара: комментарий → подтверждение → уведомление админа

**Для администраторов (`/admin`):**
- 📦 Товары — добавить / редактировать / удалить (фото скачиваются в папку)
- 🗂 Категории — добавить / удалить
- ⭐ Отзывы — модерация
- 📊 Статистика
- 🛒 Заказы — список последних заказов, ответ покупателю через бота
- ⚙️ Настройки — фото, текст, контакты, «О нас», канал с отзывами
- 📋 Скачать логи — получить файл `bot.log`

## Фото товаров

**Конвенция имён файлов:** `1.jpg`, `2.png`, `3.jpeg` … (до 10 на товар)

Поддерживается и старый формат: `photo_01.jpeg` — число в имени файла.

**Куда класть:**
- Новые товары (добавлены через бота): `product_photos/prod_<id>/1.jpg`, `2.jpg` …
- Seed-фото: `seed_photos/<папка>/` — работают автоматически (если задан `seed_folder` в БД)
- Или явно укажи папку через `/admin` → Товары → Редактировать → Папка с фото

**Через бота:** при добавлении товара фото скачиваются локально автоматически.

## Заполнение товаров (первый запуск)

`seed_products.py` **больше не нужно запускать** — при первом старте JSON-хранилища каталог создаётся автоматически, а фото читаются с диска напрямую.

Для существующих seed-товаров: через `/admin` → Товары → Редактировать → Папка с фото — укажи путь `seed_photos/1_hoodie_print` и т.д.

## User preferences

- Только Telegram-бот, без веб-интерфейса
- Язык бота: русский
- Админ-панель внутри бота через `/admin`

## Gotchas

- `python3.11` — не `python` или `python3` (для ручного запуска)
- `aiogram==3.13.1` требует `aiohttp<3.11` (зафиксировано в requirements.txt)
- Отзывы требуют одобрения модератора перед публикацией
- При ответе на заказ — нажми «✉️ Написать покупателю» в уведомлении и введи текст
